- เว็บ / มือถือ: `https://kong2540.github.io/KN-Studio/` (ต้องออนไลน์)
- ทำงานบนเบราว์เซอร์อย่างเดียว (Chrome / Edge / Safari) · ติดตั้งเป็นแอปจากเบราว์เซอร์ได้ (เมนู ⋮ → ติดตั้งแอป)
- เชื่อม AutoCAD ผ่านไฟล์ DXF: ส่งออก (เลือกรุ่น R12–2018) และนำเข้ากริด เสา คาน จากแบบ AutoCAD
- บัญชีผู้ใช้แยกจาก KTY Hub: สมัคร → ยืนยันอีเมล → แอดมินอนุมัติและกำหนดสิทธิ์

## ติดตั้งครั้งแรก (ทำครั้งเดียว)

### 1. Supabase
1. เข้า <https://supabase.com> → **New project** ตั้งชื่อ `kn-studio` เลือก Region **Southeast Asia (Singapore)**
2. **SQL Editor → New query** วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งหมด แล้วกด **Run**
3. **Authentication → URL Configuration**
   - Site URL: `https://kong2540.github.io/KN-Studio/`
   - Redirect URLs: เพิ่ม `https://kong2540.github.io/KN-Studio/`
4. **Project Settings → API** คัดลอก **Project URL** และ **Publishable key** (anon public) ไปใส่ใน `config.js`
   > ห้ามใส่ `service_role` / secret key ในไฟล์ใด ๆ ของ repo นี้

### 2. GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo `KN-Studio` (รวม `.nojekyll`, `vendor`, `supabase`)
2. **Settings → Pages** → Source: *Deploy from a branch* → Branch `main` / `(root)` → Save
3. เปิด `https://kong2540.github.io/KN-Studio/` แล้ว **สมัครด้วย kittiwat.nach@gmail.com**
   บัญชีนี้จะเป็นแอดมินอัตโนมัติ (ยืนยันอีเมลก่อนเข้าสู่ระบบ)

## หน้าต่างผลลัพธ์ (รอบ B)
- รายละเอียดคาน/แผ่นงาน · ตารางดัดเหล็ก · Bar Cut · จัดหน้า PDF · ตั้งค่า เปิดเป็นหน้าต่างลอยจากหน้าทำงาน
- ลากหัวเพื่อย้าย · ลากมุมขวาล่างปรับขนาด · ▁ ย่อเก็บ (แถบด้านล่าง) · ▢ ขยายเต็ม · ↗ เปิดเป็นหน้าเต็ม · จำขนาด/ตำแหน่ง
- เลือกคานในแปลน → หน้าต่างรายละเอียดคานเปลี่ยนตาม
- หน้าต่างทำงานชนิด "รายละเอียดคาน" วางคู่กับแปลน/รูปด้าน/3D ได้
- ตั้งค่า → หน้าต่างผลลัพธ์: เลือกได้ว่าแต่ละอย่างเปิดเป็นหน้าต่างลอยหรือเต็มหน้า

## หน้าทำงานแบบ ETABS (รอบ A)
- เมนูบน: ไฟล์ · แก้ไข · มุมมอง · กำหนด · วาด · เลือก · ผลลัพธ์ · ตั้งค่า
- กำหนด → ข้อมูลชั้น (Story Data) / ข้อมูลกริด (Grid Data) / หน้าตัด / กลุ่มคาน / เกณฑ์จุดต่อต่างระดับ
- Properties ด้านขวาเปลี่ยนตามสิ่งที่เลือก: คาน (หน้าตัด b×h ระดับ Top เหล็ก) · เสา · กริด · ชั้น (ชื่อ ระดับ ชนิด)
- แถบสถานะ: ระดับ · พิกัด X/Y · เครื่องมือ · จำนวนที่เลือก · ⚠ คำเตือนทั้งหมด
- ตรวจเหล็กปลอกที่จุดดัดเหล็ก (ACI 318-19 10.7.6.4)

## โต๊ะทำงานแบบ ETABS
- หน้าเดียวรวม แปลน · รูปด้าน · 3D · แบ่งจอ 1 / 2 / 3 / 4 หน้าต่าง · หน้าต่างที่ใช้งานมีกรอบสีทอง
- แต่ละหน้าต่างเลือกชนิดเองได้: แปลน (ชั้นไหนก็ได้ ▲▼) · รูปด้านตามกริดหลักหรือกริดช่วย (◀▶) · 3D (1 หน้าต่าง)
- Model Explorer ด้านซ้าย: คลิกชั้น / กริด / 3D / กลุ่มคาน เพื่อเปิดในหน้าต่างที่ใช้งาน
- การเลือกใช้ร่วมกันทุกหน้าต่าง · ดับเบิลคลิกคานในรูปด้านเพื่อแก้ไข · Delete ลบได้
- "แสดง ▾" ต่อหน้าต่าง: คาน / เสา / ป้าย / เหล็กเสริม / เฉพาะชั้น · HI แยกดู · HH ซ่อน · ↺ แสดงทั้งหมด · ⤢ ขยายเต็ม
- มือถือ: แสดงทีละหน้าต่าง สลับด้วยแท็บ · ☰ Model / ⓘ Properties เป็นลิ้นชัก

## กลุ่มคานต่อเนื่อง · กลุ่มเหล็ก
- เลือกคานที่ต่อกันในแนวเดียว (Shift+คลิกในแปลน / Shift+คลิกชื่อคานในหน้า Detail / ปุ่ม ⧉ กลุ่มคาน) → "⧉ จัดกลุ่มคาน"
- คานยังเป็นคนละชิ้น แต่จัดเหล็กรวมทั้งแนวในหน้า Detail (เหล็กล้วงข้ามคาน ระยะทาบ ระดับ หน้าตัด)
- ตั้งชื่อกลุ่ม และเลือกชื่อในแบบ/ตารางเหล็ก: ชื่อกลุ่ม · รายชื่อคาน · กำหนดเอง · แสดง/ซ่อนในแปลน · ยกเลิกกลุ่มได้ (Undo ได้)
- ตารางเหล็ก / Bar Cut นับเหล็กของกลุ่มแทนคานสมาชิก
- เหล็กหลายเส้น: Shift+คลิกบนรูป แก้ชั้น ขนาด จำนวน ปลาย ระยะเยื้อง พร้อมกัน · "รวมเป็นกลุ่มเหล็ก" คลิกเส้นเดียวเลือกทั้งกลุ่ม

## แก้ไขแปลน (แบบ Revit)
- เลือก: คลิก / Shift+คลิก / ลากกรอบ (ซ้าย→ขวา ในกรอบ · ขวา→ซ้าย แตะกรอบ) / "เลือกหลายชิ้น" บนมือถือ
- ลบ: ปุ่ม Delete หรือปุ่ม 🗑 · เสาที่มีคานวางอยู่ / กริดที่ยังมีชิ้นส่วน จะแจ้งเตือนให้แก้เอง · Undo ได้
- กริด: ปุ่ม "+ กริด" · คลิกกริดแล้วลากย้าย หรือแก้ตัวเลขระยะสีฟ้าถึงกริดข้างเคียง
- ดับเบิลคลิกคาน (แปลน / 3D / หน้าคาน "แก้ไข / แยกช่วง…"): หน้าตัด · ระดับ Top · เหล็ก · เปลี่ยนชื่อช่วง = แยกเป็นคานใหม่

## PDF (ทุกโมดูล · ใช้บนมือถือได้)
- ปุ่ม "ดาวน์โหลด PDF" สร้างไฟล์ .pdf ในเครื่องทันที ไม่ต้องผ่านหน้าพิมพ์
- แบบเวกเตอร์ ฝังฟอนต์ Sarabun (จัดสระ/วรรณยุกต์ไทย) · มีตัวเลือกแบบภาพ
- มือถือ: ปุ่ม "แชร์ / บันทึกลงเครื่อง" ส่งเข้า LINE อีเมล หรือ Files ได้

## โต๊ะทำงาน (3D ทั้งอาคาร)
- เมนู โต๊ะทำงาน: ดู 3D ทั้งอาคาร (WebGL) หมุน/เลื่อน/ซูม แบบ Revit · มุมมอง บน/หน้า/ขวา/หลัง/ซ้าย/ISO/ใต้
- กล่องเปิด/ปิด: หมวด, ระดับ, หน้าตัดคาน/เสา · เหล็ก: ปิด / เฉพาะที่เลือก / ทั้งอาคาร
- ระดับอ้างอิง (ชานพัก อกไก่ คานรับหลังคา) ไม่ตัดความสูงเสา
- คลิกเลือก → Properties: เปลี่ยนหน้าตัด ระดับคาน หมุนเสา เปิดรายละเอียด · ซ่อน/แยกดู · Section Box · บันทึกมุมมอง · ส่งภาพไปจัดหน้า PDF
- (รอบถัดไป) วาด/ย้ายชิ้นส่วนใน 3D

## การแสดงผลแบบ Revit · คีย์ลัด · ระยะทาบ
- ตั้งค่า → การแสดงผล: ชุดสี Revit (สว่าง) / Revit (มืด) / แบบเดิม · ปรับสีพื้นหลัง คอนกรีตคาน/เสา เส้นขอบ ชิ้นที่เลือก กริด ระดับ · สีเหล็กตามขนาด/ชั้น/สีเดียว · เหล็ก 3D เป็นแท่งกลมตามขนาดจริง
- 3D: Wireframe · Hidden Line · Shaded · Consistent Colors · Realistic · X-ray · แปลน/รูปด้านพื้นขาวแบบ Revit
- คีย์ลัด 2 ตัวอักษรแบบ Revit (HI, HH, HR, WF, SD, ZE, BX, BM, DE, 3D, PL, EL, LP ฯลฯ) แก้ได้ในตั้งค่า
- ปุ่ม "ระยะทาบ" / "โซนทาบ" ในแถบ PROFILE แสดงช่วงทาบ (เช่น ทาบ 0.82 (41d)) ในหน้าจอและแผ่นงาน · ทาบนอกโซนขึ้นสีส้ม ⚠ และเข้ารายการคำเตือน

## ธีม · ปรับหน้าจอ · ยุบแผง
- ธีมสว่าง / มืด / ตามเครื่อง (ปุ่ม ☀ ☾ ◐ มุมขวาบน หรือคีย์ TT) · ค่าเริ่มต้นตามเครื่อง · หน้าต่างวาดเปลี่ยนชุดสีตามธีม (Display = อัตโนมัติ)
- ตั้งค่า → ธีมโปรแกรม: สีหลัก 21 ตัวต่อโหมด, สีแยกทุกส่วน (แถบบน เมนู Explorer Properties เครื่องมือวาด หัวหน้าต่าง ปุ่มแต่ละแบบ ช่องกรอก), ขนาดแถบเมนู, ความโค้งมุม, บันทึก/ส่งออก/นำเข้าธีม
- โหมดปรับหน้าจอ 🎨: คลิกปุ่มใดก็ได้เพื่อตั้งสีเฉพาะปุ่มหรือซ่อนปุ่ม · รายการ "ปุ่มบนหน้าจอ" ติ๊กแสดง/ซ่อน
- หน้าต่างที่ทำงานอยู่มีกรอบเน้น + ป้าย "● กำลังทำงาน" และแสดงในแถบสถานะ · แถบเลื่อนสีตามธีม
- ยุบ Model Explorer / Properties (« » หรือ F3 / F4) ลากขอบปรับความกว้าง · Properties ยุบได้ทีละหมวด (⊟ ⊞ ยุบ/ขยายทั้งหมด)

## แบบ AutoCAD · ไอคอน · พอดีจอ
- ปุ่มเครื่องมือเป็นไอคอน ชี้ค้างเพื่อดูการ์ด: ชื่อ · หน้าที่ · วิธีใช้ · คีย์ลัด (มือถือ: กดค้าง) · ตั้งค่า → ธีม เลือก ไอคอน / ไอคอน+ข้อความ / ข้อความ
- F8 ORTHO · F3 OSNAP · F10 POLAR (คลิกขวาที่ POLAR เปลี่ยนมุม 15/30/45/90°) · Shift ค้างสลับชั่วคราว · ปุ่มเปิดปิดในแถบสถานะ
- Dynamic Input: ระหว่างวาดคานอิสระ/กริดช่วย พิมพ์ความยาว (Tab = มุม) แล้ว Enter
- ป้ายคานบนแปลนเป็นชื่อคานที่ตั้ง (ไม่มี *) · คานในกลุ่มแสดงชื่อกลุ่ม · ชื่อกลุ่มเรียงตามลำดับที่คลิก (B2 แล้ว B1 → B2+B1) · เลือกกลุ่ม + คานใหม่แล้วจัดกลุ่ม = ต่อท้าย
- ทุกหน้าพอดีจอ เลื่อนเฉพาะในแผง · ตั้งค่ามีเมนูหัวข้อด้านซ้าย

## แบบ Revit (รอบล่าสุด)
- 3D รวมเป็นชิ้นเดียว: คานหยุดที่ผิวเสา ซ่อนเส้นตรงรอยต่อคอนกรีต (Hidden Line / Shaded)
- View Control Bar ใต้ทุกหน้าต่าง: มาตราส่วน 1:10–1:500 (ตัวอักษร/สัญลักษณ์ตามมาตราส่วน) · Detail Level Coarse/Medium/Fine · Visual Style (3D)
- รูปด้าน: ป้ายชื่อคาน/กลุ่มแสดงครั้งเดียวต่อคาน ไม่ทับกัน
- หน้า Detail: ชื่อคานจริงบน Profile · เอาป้าย "แบบ N" ออก · ข้อความใต้ช่วงและแถวระยะจัดไม่ให้ทับกัน
- แผง SECTION แก้จำนวน/ขนาดเหล็กบน ล่าง เสริมกลางช่วง และปลอกได้ทันที (เฉพาะช่วงที่ตัด เฉพาะค่าที่แก้)

- ชื่อคานบนแปลน/รูปด้าน/3D = ชื่อของคานเอง (ซ้ำได้) · กลุ่มเป็นกรอบม่วงจาง ดูชื่อกลุ่มใน Explorer/Properties
- หน้า Detail พอดีจอ: Profile บน (ย่อเต็มความกว้าง) · ลากเส้นแบ่ง · แท็บล่าง 3D / แผ่นแบบ / ตาราง Bending / ส่งออก / ตัวกรองสีเหล็ก · ช่องเลือกคาน · แผงคุณสมบัติยุบได้ทีละหมวด

- ปุ่มเส้นบาง/หนา (Thin Lines) ไอคอน ≡ ข้างมาตราส่วนทุกหน้าต่างและแถบ PROFILE · คีย์ TL · ใช้ร่วมทั้งโปรแกรม
- ตั้งชื่อคานซ้ำกันได้ (แยกด้วยตำแหน่ง) · มีแจ้งเตือนเล็กน้อย

- หน้า Detail แบ่งหน้าต่าง 1/2/3/4 แบบโต๊ะทำงาน: แต่ละหน้าต่างเลือก PROFILE · 3D · แผ่นแบบ/ตาราง · ตัวกรอง · ลากเส้นแบ่ง · ดับเบิลคลิกหัวหน้าต่างขยายเต็ม
- คานชนกันโดยไม่มีเสาต่อเนื้ออัตโนมัติแบบ Revit (แปลนเป็นรูปเดียว · 3D เป็นก้อนเดียว · มุม L ไม่แหว่ง)

## แถบ MODIFY แบบ Revit (หน้าโต๊ะทำงาน)
Align (AL) · Offset (OF) · Mirror Pick/Draw (MM/DM) · Move (MV) · Copy (CO, หลายชิ้น) · Rotate (RO) · Array (AR) · Scale (RE) · Trim/Extend to Corner (TR) · Trim/Extend Single/Multiple · Split (SL) · Split with Gap · Join/Unjoin ปลายคาน · Pin/Unpin (PN/UP) · Match Type (MA) · Delete — ใช้ร่วมกับ ORTHO/OSNAP/POLAR และพิมพ์ระยะ (Dynamic Input) · Copy คัดลอกเหล็กไปด้วยและผูกกริดอัตโนมัติถ้าปลายตรงจุดตัด

## แผ่นแบบ (Sheet)
- หน้า Detail: มุมมองแยกเป็น แผ่นแบบ · ตาราง Bending · ส่งออก · ตั้งค่าแผ่นแบบ เปิดพร้อมกันได้หลายหน้าต่าง
- แผ่นแบบพอดีหน้าต่างเสมอ ไม่มีแถบเลื่อน · ล้อเมาส์ซูมที่เมาส์ · ลากเพื่อเลื่อน · ดับเบิลคลิกพอดี · ปุ่ม ⤢ เต็มจอ (Esc ออก)
- ✎ แก้ไขการจัดวาง: หน้าแก้ไขแผ่นแบบเต็มจอ (รายการวัตถุ · จัดชิด/กระจาย · เส้นช่วยจัดแนว · ข้อความ ลูกศร กรอบ เมฆแก้ไข · ซ่อน/ล็อก · ดับเบิลคลิกเข้าไปจัดภายในกลุ่ม · คลิกขวาเปิดคาน) · ข้อมูลเหล็กล็อกไว้

## เมาส์ · Snap · วัดระยะ · ระยะเยื้อง (แบบ AutoCAD/Revit)
- ตั้งค่า → เมาส์และ Snap: Crosshair (ขนาด 5–100% · สี) · Pickbox · Aperture · ขนาดเครื่องหมาย Snap · ทิศ/ความเร็วล้อซูม · คลิกขวา (เมนู / ทำซ้ำ / Enter)
- OSNAP เลือกโหมดได้ (คลิกขวาที่ปุ่ม OSNAP): จุดตัด · ศูนย์เสา · มุมเสา · ปลายคาน · กึ่งกลางคาน · แนวศูนย์กลางคาน · ขอบคาน · ตั้งฉาก · บนกริด — มีสัญลักษณ์และชื่อ snap แบบ AutoCAD
- ME วัดระยะ (ระยะ ΔX ΔY มุม) · DI เส้นบอกระยะถาวร (เลือกแสดงในแปลน / หน้าจัดหน้า PDF · คลิกแล้ว Delete เพื่อลบ)
- ระยะเยื้องคาน e (มม.) ใน Properties ต่อช่วงที่เลือก (เลือกทั้งคาน = ทุกช่วง) + ปุ่ม กึ่งกลาง / ชิดขอบนอกเสา / ชิดขอบในเสา · แสดงในแปลน 3D (รวมเหล็ก) และแผ่นแปลน

## แอดมิน: ค่าเริ่มต้นระบบ · ชื่อในแอป
- **หน้าแอดมิน → ค่าเริ่มต้นระบบ**: บันทึกค่าตั้งค่าปัจจุบันของแอดมิน (ระยะทาบ ระยะงอ ปัดเศษ แผ่นแบบ ฯลฯ) เป็นค่าระบบ · ไม่รวมธีม การแสดงผล เมาส์ และเลย์เอาต์หน้าต่าง
- **หน้าแอดมิน → ชื่อในแอป**: เปลี่ยนคำที่แสดงทั้งแอป เช่น `KN-Detail` → `รายละเอียดคาน` · ติ๊ก "ทั้งข้อความเท่านั้น" เพื่อแทนเฉพาะข้อความที่ตรงทั้งหมด · มีผลทันทีกับผู้ใช้ทุกคน
- ผู้ใช้: **ตั้งค่า → ค่าระบบ → รีเซ็ตเป็นค่าระบบ** (ธีม/การแสดงผล/เมาส์ของตัวเองไม่ถูกเปลี่ยน) · โครงการใหม่ที่ยังว่างจะใช้ค่าระบบอัตโนมัติ
- เก็บในตาราง `app_settings` เดิม (key `sys_defaults`, `labels`) · สิทธิ์เขียนเฉพาะ `profiles.role = 'admin'` · **ไม่ต้องรัน SQL เพิ่ม**

## AutoCAD (DXF)
- ส่งออก: แผ่นงานคาน / ทั้งโครงการ / แปลน → เลือกรุ่น AutoCAD ได้ (R12, 2000, 2004, 2007, 2010, 2013, 2018) · ภาษาไทยใช้ฟอนต์ที่ตั้งไว้ (ค่าเริ่มต้น TH Sarabun New)
- นำเข้า: AutoCAD → `SAVEAS` เป็น DXF → KN Studio หน้าแปลน → **นำเข้าจาก AutoCAD (DXF)** → เลือกเลเยอร์กริด / เสา / คาน
- ไฟล์ .dwg เปิดในเบราว์เซอร์ไม่ได้ ต้องบันทึกเป็น .dxf ก่อน
