# KN Studio

โปรแกรมช่วยเขียนแบบเหล็กเสริมและคำนวณตัดเหล็ก (KN-Detail · Bar Cut) ของ KTY Construction

- เว็บ / มือถือ: `https://kong2540.github.io/KN-Studio/` (ต้องออนไลน์)
- ทำงานบนเบราว์เซอร์อย่างเดียว (Chrome / Edge / Safari) · ติดตั้งเป็นแอปจากเบราว์เซอร์ได้ (เมนู ⋮ → ติดตั้งแอป)
- เชื่อม AutoCAD ผ่านไฟล์ DXF: ส่งออก (เลือกรุ่น R12–2018) และนำเข้ากริด เสา คาน จากแบบ AutoCAD
- บัญชีผู้ใช้แยกจาก KTY Hub: สมัคร → ยืนยันอีเมล → แอดมินอนุมัติและกำหนดสิทธิ์

## ติดตั้งครั้งแรก (ทำครั้งเดียว)

### 1. Supabase
1. เข้า <https://supabase.com> → **New project** ตั้งชื่อ `kn-studio` เลือก Region **Southeast Asia (Singapore)**
2. **SQL Editor → New query** วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งหมด แล้วกด **Run**
3. **Authentication → URL Configuration**
   - Site URL: `https://kong2540.github.io/KN-Studio/`
   - Redirect URLs: เพิ่ม `https://kong2540.github.io/KN-Studio/`
4. **Project Settings → API** คัดลอก **Project URL** และ **Publishable key** (anon public) ไปใส่ใน `config.js`
   > ห้ามใส่ `service_role` / secret key ในไฟล์ใด ๆ ของ repo นี้

### 2. GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo `KN-Studio` (รวม `.nojekyll`, `vendor`, `supabase`)
2. **Settings → Pages** → Source: *Deploy from a branch* → Branch `main` / `(root)` → Save
3. เปิด `https://kong2540.github.io/KN-Studio/` แล้ว **สมัครด้วย kittiwat.nach@gmail.com**
   บัญชีนี้จะเป็นแอดมินอัตโนมัติ (ยืนยันอีเมลก่อนเข้าสู่ระบบ)

| KN-Detail · คาน, Bar Cut, ตั้งค่ามาตรฐาน | ไม่เห็น / ดูอย่างเดียว / แก้ไขได้ |

- แอดมินตั้งสิทธิ์ตั้งต้นของแต่ละบทบาท และปรับรายคนได้ที่ **หน้าแอดมิน**
- แอดมินแก้ช่องข้อมูลในหน้าสมัครสมาชิกได้เอง (เพิ่ม/ลบ/เรียง/บังคับกรอก)
- ข้อมูลโครงการเก็บที่ Supabase ป้องกันด้วย Row Level Security: เห็นเฉพาะโครงการของตัวเองหรือที่ถูกแชร์

## โต๊ะทำงานแบบ ETABS
- หน้าเดียวรวม แปลน · รูปด้าน · 3D · แบ่งจอ 1 / 2 / 3 / 4 หน้าต่าง · หน้าต่างที่ใช้งานมีกรอบสีทอง
- แต่ละหน้าต่างเลือกชนิดเองได้: แปลน (ชั้นไหนก็ได้ ▲▼) · รูปด้านตามกริดหลักหรือกริดช่วย (◀▶) · 3D (1 หน้าต่าง)
- Model Explorer ด้านซ้าย: คลิกชั้น / กริด / 3D / กลุ่มคาน เพื่อเปิดในหน้าต่างที่ใช้งาน
- การเลือกใช้ร่วมกันทุกหน้าต่าง · ดับเบิลคลิกคานในรูปด้านเพื่อแก้ไข · Delete ลบได้
- "แสดง ▾" ต่อหน้าต่าง: คาน / เสา / ป้าย / เหล็กเสริม / เฉพาะชั้น · HI แยกดู · HH ซ่อน · ↺ แสดงทั้งหมด · ⤢ ขยายเต็ม
- มือถือ: แสดงทีละหน้าต่าง สลับด้วยแท็บ · ☰ Model / ⓘ Properties เป็นลิ้นชัก

## กลุ่มคานต่อเนื่อง · กลุ่มเหล็ก
- เลือกคานที่ต่อกันในแนวเดียว (Shift+คลิกในแปลน / Shift+คลิกชื่อคานในหน้า Detail / ปุ่ม ⧉ กลุ่มคาน) → "⧉ จัดกลุ่มคาน"
- คานยังเป็นคนละชิ้น แต่จัดเหล็กรวมทั้งแนวในหน้า Detail (เหล็กล้วงข้ามคาน ระยะทาบ ระดับ หน้าตัด)
- ตั้งชื่อกลุ่ม และเลือกชื่อในแบบ/ตารางเหล็ก: ชื่อกลุ่ม · รายชื่อคาน · กำหนดเอง · แสดง/ซ่อนในแปลน · ยกเลิกกลุ่มได้ (Undo ได้)
- ตารางเหล็ก / Bar Cut นับเหล็กของกลุ่มแทนคานสมาชิก
- เหล็กหลายเส้น: Shift+คลิกบนรูป แก้ชั้น ขนาด จำนวน ปลาย ระยะเยื้อง พร้อมกัน · "รวมเป็นกลุ่มเหล็ก" คลิกเส้นเดียวเลือกทั้งกลุ่ม

## แก้ไขแปลน (แบบ Revit)
- เลือก: คลิก / Shift+คลิก / ลากกรอบ (ซ้าย→ขวา ในกรอบ · ขวา→ซ้าย แตะกรอบ) / "เลือกหลายชิ้น" บนมือถือ
- ลบ: ปุ่ม Delete หรือปุ่ม 🗑 · เสาที่มีคานวางอยู่ / กริดที่ยังมีชิ้นส่วน จะแจ้งเตือนให้แก้เอง · Undo ได้
- กริด: ปุ่ม "+ กริด" · คลิกกริดแล้วลากย้าย หรือแก้ตัวเลขระยะสีฟ้าถึงกริดข้างเคียง
- ดับเบิลคลิกคาน (แปลน / 3D / หน้าคาน "แก้ไข / แยกช่วง…"): หน้าตัด · ระดับ Top · เหล็ก · เปลี่ยนชื่อช่วง = แยกเป็นคานใหม่

## PDF (ทุกโมดูล · ใช้บนมือถือได้)
- ปุ่ม "ดาวน์โหลด PDF" สร้างไฟล์ .pdf ในเครื่องทันที ไม่ต้องผ่านหน้าพิมพ์
- แบบเวกเตอร์ ฝังฟอนต์ Sarabun (จัดสระ/วรรณยุกต์ไทย) · มีตัวเลือกแบบภาพ
- มือถือ: ปุ่ม "แชร์ / บันทึกลงเครื่อง" ส่งเข้า LINE อีเมล หรือ Files ได้

## โต๊ะทำงาน (3D ทั้งอาคาร)
- เมนู โต๊ะทำงาน: ดู 3D ทั้งอาคาร (WebGL) หมุน/เลื่อน/ซูม แบบ Revit · มุมมอง บน/หน้า/ขวา/หลัง/ซ้าย/ISO/ใต้
- กล่องเปิด/ปิด: หมวด, ระดับ, หน้าตัดคาน/เสา · เหล็ก: ปิด / เฉพาะที่เลือก / ทั้งอาคาร
- ระดับอ้างอิง (ชานพัก อกไก่ คานรับหลังคา) ไม่ตัดความสูงเสา
- คลิกเลือก → Properties: เปลี่ยนหน้าตัด ระดับคาน หมุนเสา เปิดรายละเอียด · ซ่อน/แยกดู · Section Box · บันทึกมุมมอง · ส่งภาพไปจัดหน้า PDF
- (รอบถัดไป) วาด/ย้ายชิ้นส่วนใน 3D

## AutoCAD (DXF)
- ส่งออก: แผ่นงานคาน / ทั้งโครงการ / แปลน → เลือกรุ่น AutoCAD ได้ (R12, 2000, 2004, 2007, 2010, 2013, 2018) · ภาษาไทยใช้ฟอนต์ที่ตั้งไว้ (ค่าเริ่มต้น TH Sarabun New)
- นำเข้า: AutoCAD → `SAVEAS` เป็น DXF → KN Studio หน้าแปลน → **นำเข้าจาก AutoCAD (DXF)** → เลือกเลเยอร์กริด / เสา / คาน
- ไฟล์ .dwg เปิดในเบราว์เซอร์ไม่ได้ ต้องบันทึกเป็น .dxf ก่อน
